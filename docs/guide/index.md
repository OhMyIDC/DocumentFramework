# 指南

这一组文档说明框架的结构、构建流程和嵌入方式。

## 阅读顺序

1. [快速开始](./start.md)：先把站点跑起来，理解一次构建发生了什么。
2. [嵌入到宿主](./embed.md)：把文档挂进已有 Vue 应用的指定路径。
3. [Markdown 能力](./markdown.md)：代码高亮、提示块、标题锚点和相对链接。

## 设计原则

| 原则         | 含义                                            |
| ------------ | ----------------------------------------------- |
| 宿主拥有应用 | 不创建第二个 router，不接管 HTML 入口           |
| 构建期编译   | Markdown 在构建时变成渲染函数，运行时不带解析器 |
| 样式不越界   | 所有样式收在 `.odocs` 命名空间里                |
| 可替换主题   | 默认主题只是一组布局原语的组合                  |
